# Portfolio direction

A developer portfolio first: who CJ is and what he builds, inside one screen.
Personality is seasoning: the paper-and-jollof look, the type, the particle
"CJ." mark, an open-to-work stamp. Not a life story.

## Page order

1. **Hero:** name, role, "I build web products people actually _use._", open to
   work and freelance stamp, See the work and Email me, particle "CJ." mark,
   Lagos clock.
2. **Work:** each project acted out, Rise Classroom first.
3. **About:** short professional copy, what he's on now, grouped stack, GitHub
   activity (live, revalidated daily, hidden if the source is down).
4. **Contact.**

## Look

| Token    | Value     | Role               |
| -------- | --------- | ------------------ |
| paper    | `#F3EADB` | background         |
| ink      | `#1A120D` | type and particles |
| jollof   | `#B8321A` | accent             |
| plantain | `#E9A93B` | spare second note  |

Anybody (variable width) for display, condensed for headlines and wide italic
for the jollof turn word; DM Mono for labels. Project scenes sit in dark screens.

## Out of scope

Life story chapters, music, photos.
